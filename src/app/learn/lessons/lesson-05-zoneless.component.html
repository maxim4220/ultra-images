Zoneless change detection

This app does not load zone.js. Angular no longer monkey-patches setTimeout or XHR. The view updates when a signal changes, a template listener runs, setInput is called, or you call markForCheck().

Click handlers still refresh the view, so plainCount++ in a (click) looks fine. The trap is async work: HTTP, timers, WebSockets. Put that data in a signal (or toSignal) and zoneless just works. That is why the Giphy service returns an Observable that the page converts with toSignal().
